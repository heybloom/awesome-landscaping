# Contributing to Awesome Landscaping

Contributions are welcome and highly appreciated! By contributing, you help make this list a valuable resource for landscaping businesses, designers, solo operators, and developers.

Please take a moment to review these guidelines before submitting a pull request.

## Contribution Guidelines

1. **Check for Duplicates:** Before suggesting a new tool, database, or resource, please search this repository to ensure it isn't already included.
2. **Alphabetical Order:** Keep the lists in alphabetical order within each category.
3. **Format Consistency:** Use the following format for all link listings:
   ```markdown
   * [Name](https://example.com) - Short, objective description. [Pricing/License Type]
   ```
   *Example:*
   ```markdown
   * [HeyBloom](https://heybloom.ai) - AI-powered scheduling, marketing, and client manager built for landscaping. [Freemium]
   ```
4. **Description Guidelines:**
   - Keep descriptions objective and concise.
   - Avoid marketing jargon, sales pitches, or excessive exclamation marks.
   - Start with a capital letter and end with a period.
5. **Categorization:** Place your suggested resource in the most relevant category. If you believe a new category is needed, suggest it in your PR.
6. **Workable Links:** Verify that the link is correct, secure (`https://`), and goes directly to the tool's homepage.

## How to Contribute

1. Fork this repository to your own GitHub account.
2. Clone the repository to your local machine.
3. Create a new branch for your changes:
   ```bash
   git checkout -b add-[tool-name]
   ```
4. Make your additions or updates to `README.md`.
5. Run the validation checks (if applicable) to ensure all links are valid.
6. Commit your changes with a clear message:
   ```bash
   git commit -m "Add [Tool Name] to [Category Name] section"
   ```
7. Push your branch to your fork:
   ```bash
   git push origin add-[tool-name]
   ```
8. Open a Pull Request (PR) from your fork's branch to our `main` branch.

Thank you for helping improve the Awesome Landscaping list!
